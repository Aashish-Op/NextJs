## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Prisma

Prisma ORM 7 is configured to use SQLite in `dev.db`. Define models in
`prisma/schema.prisma`; the generated client is available from `lib/prisma.js`
and is regenerated after dependency installation.

- Create and apply a migration after adding models: `npm run db:migrate -- --name init`
- Regenerate the client after schema changes: `npm run db:generate`
- Open Prisma Studio: `npm run db:studio`

The database URL defaults to `file:./dev.db` and can be overridden with
`DATABASE_URL` in `.env`.
